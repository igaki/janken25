# 2025-10-07_ユーザログイン機能調査.md

## 調査日
2025年10月7日

## 調査目的
`reference/springboot_samples` の構成・実装例を参考に、Spring Bootアプリケーションでユーザがログインできる機能の実装方法を調査する。

## 調査内容
- Spring Bootでは、ユーザ認証機能の実装にSpring Securityを利用するのが一般的。
- コントローラ層（controller）、サービス層（service）、モデル層（model）に分離したMVC構成が推奨される。
- ユーザ情報はモデルクラス（例：User）で管理し、DBやメモリ上で保持。
- ログイン画面（login.html）を `templates` ディレクトリに配置し、Thymeleafでフォームを作成。
- 認証処理はSpring Securityの設定クラス（例：SecurityConfig）で行う。
- 認証成功後はセッション管理によりユーザ情報を保持。
- サンプル構成例：
  - controller: LoginController.java
  - service: UserService.java
  - model: User.java
  - config: SecurityConfig.java
  - templates: login.html, home.html

## 発見事項
- Spring Securityを導入することで、認証・認可機能を簡単に追加可能。
- ユーザ情報はDB（例：H2, MySQL）やメモリ上で管理できる。
- 認証処理は自作のサービスクラス（UserService）で拡張可能。
- ログイン画面はThymeleafテンプレートで作成し、POSTで認証リクエストを送信。
- 認証後はセッションでユーザ情報を保持し、必要に応じてコントローラで参照可能。

## 推奨事項
- Spring Securityを利用し、MVC構成でログイン機能を実装する。
- ユーザ情報はモデルクラスで管理し、サービス層で認証処理を実装。
- ログイン画面は `templates/login.html` に配置。
- 認証設定は `config/SecurityConfig.java` で行う。
- テストコードも `test/java/` 配下に作成。
